Se você tem apenas o Python instalado e não usa uma IDE, a maneira mais simples é salvar o script como um arquivo .py e rodá-lo no terminal usando:python comparar_procs.py


1.Salve o código em um arquivo

Abra um editor de texto simples, como Bloco de Notas (Windows) ou Nano/Vi (Linux/Mac).
Copie e cole o código atualizado no arquivo.
Salve como comparar_procs.py (certifique-se de que a extensão seja .py).
Abra o terminal e navegue até a pasta onde salvou o arquivo

No Windows (CMD ou PowerShell):

cd C:\caminho\para\a\pasta
No Linux/macOS (Terminal):

cd /caminho/para/a/pasta
Execute o script com Python

Digite no terminal:
python comparar_procs.py

Se seu sistema tiver Python 3 instalado, pode ser necessário rodar com:

python3 comparar_procs.py


2.Se quiser rodar os comandos diretamente sem salvar um arquivo:

Abra o Terminal e inicie o interpretador Python

python
Ou, se necessário:

python3
Copie e cole o código parte por parte

Primeiro, cole as funções e execute.
Depois, estabeleça a conexão manualmente.
Por fim, chame compare_procedures() com os nomes das procedures.

3.Se estiver no Linux/macOS, pode tornar o script executável:
Dê permissão de execução ao arquivo:
chmod +x comparar_procs.py

Execute diretamente:
./comparar_procs.py
